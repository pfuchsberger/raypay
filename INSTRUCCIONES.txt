RAYPAY v3 · Wallet original + rayo amarillo + trueno

IMPORTANTE: esta versión usa EXACTAMENTE la captura que facilitaste.
La imagen incluye datos de tus transacciones y los últimos cuatro dígitos
visibles de la tarjeta. GitHub Pages es público: cualquiera podrá ver la
imagen descargándola. Si te preocupa la privacidad, no publiques esa captura
sin ocultar primero esos datos.

ACTUALIZAR GITHUB PAGES DESDE WINDOWS
1. Descomprimí este ZIP. Todos los archivos deben estar en la RAÍZ del
   repositorio pfuchsberger/raypay (no dentro de la carpeta del ZIP).
2. Abrí https://github.com/pfuchsberger/raypay
3. Elegí Add file -> Upload files, y subí: index.html, app.js, sw.js,
   manifest.webmanifest, thunder.wav, wallet-background.png y la carpeta icons.
   Reemplazá las versiones previas. Confirmá con Commit changes.
4. Esperá que se publique y abrí en Safari del iPhone:
   https://pfuchsberger.github.io/raypay/?play=1&v=3
5. Tocá la pantalla para repetir el rayo con sonido.

ATAJOS
La URL de activación sigue siendo:
https://pfuchsberger.github.io/raypay/?play=1
No necesitás cambiarla. No se dibuja encima de Wallet: muestra su captura
estática dentro de RayPay, con el rayo animado encima.

IMPORTANTE SOBRE SONIDO
Safari/iOS puede impedir reproducir audio automáticamente si no hubo
interacción del usuario. Tocando la pantalla sí debería escucharse.

SI NO VES LA ACTUALIZACIÓN
1. Probá ?play=1&v=3 en Safari.
2. Cerrá RayPay y volvela a abrir.
3. Si seguís viendo la versión anterior, borrá el ícono de RayPay de la
   pantalla de inicio y agregalo de nuevo desde Safari, o borrá los datos
   del sitio correspondientes al dominio en la configuración de Safari.

Este prototipo no interactúa con tarjetas ni efectúa pagos reales.
